# SIH26090 – Artisan Marketplace

SIH 2026 project — An AI-driven platform for smart cataloging, digital
product showcasing, and market linkage for marginalized artisans.

## Project Overview

This project aims to empower marginalized artisans by providing a
digital platform to showcase their products, automatically catalog
crafts using AI, and connect artisans with wider markets.

## Tech Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB
- AI: AI-based image and text processing
- Version Control: Git + GitHub
